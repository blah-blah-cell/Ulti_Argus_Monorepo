# Argus Community Python package

This directory contains the Python packet-processing and API support package for Argus Community.

Install from the repository root:

```bash
python -m pip install -e ./Ulti_argus
```

The supported runtime is documented in the [root README](../README.md). It includes
a small train-your-own logistic baseline, but no pretrained weights, dataset,
advanced research architecture, or automated response policy.
